# Float Wheel 悬浮窗轮盘

把各插件、脚本的悬浮按钮收进一个可拖动的小圆钮。点开是一圈轮盘，里面就是它们原来的样子。

- 自动发现页面上的悬浮按钮和悬浮窗，原样收进轮盘
- 通知气泡从圆钮旁边弹出，有未读时圆钮亮点
- 轮盘里的「管理」可以逐个选择收不收
- 圆钮位置会记住，手机电脑各一份

## 安装

扩展 → 安装扩展，粘贴：

```
https://github.com/xzhouzhou758/float-wheel
```

Luker 和 SillyTavern 都能用。还在测试中，遇到点了没反应、位置不对的悬浮窗，告诉我是哪个插件。
